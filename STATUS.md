# STATUS

- Game: **COVER** (Ariel & Nina, CGDD 2026). A first-person stealth game: you sneak phone use in a sealed, surveilled school, Clearview Academy (est. 1952, "What is seen, is safe"). The phone has been passed down through the same seat, Seat 31, since 1979.
- Stage: v1. Title, 4 chapters (~20 min), an end page after every chapter, two endings. Clearview art pass and generated sound.
- Verb: watch, peek, act, hide (plus listen; in Ch.3, pretend to sleep).
- Win: each chapter's goal (contact the triangle student / deliver the message and reach the stairs / signal the dorm across the yard / choose an ending).
- Loss: three warnings (never shown as a number). The watcher takes the phone; retry from the start of the chapter.
- Flowchart and tunables table are written to `docs/` and `site/data/` by `CGDD/Export Trace Docs`.
- `DEVLOG.md` logs only the game itself.
- The student site defaults to English. The nav can switch to Chinese. Chrome strings live in `site/lang.js`. Exported docs are English; Chinese is a display translation.
